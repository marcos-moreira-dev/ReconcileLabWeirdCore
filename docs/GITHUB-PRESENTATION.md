# Presentación del repositorio en GitHub

## Mensaje principal

ReconcileLab es un mismo laboratorio de conciliación implementado en dos épocas:

```text
C++ / wxWidgets / Windows XP
Java 21 / JavaFX / Windows 11
```

La comparación es intencional. El valor del repositorio no está sólo en el
algoritmo, sino en observar cómo el mismo modelo de dominio, flujo de trabajo y
gramática espacial sobreviven a dos toolkits y dos generaciones de escritorio.
