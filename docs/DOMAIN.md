# Dominio

El problema visible es la conciliación de montos.

Existe un monto total observado —por ejemplo un depósito o abono— y varios
movimientos candidatos. La relación entre el total y sus componentes puede
estar ausente, incompleta o ser ambigua.

V1 busca subconjuntos de montos positivos cuya suma sea exactamente el monto a
conciliar.

El programa identifica combinaciones compatibles. No afirma que una
combinación sea la explicación histórica real cuando los datos no permiten
demostrarlo.
