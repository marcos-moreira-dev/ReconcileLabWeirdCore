# Capturas de pantalla

Las imágenes se conservan sin recortes ni retoques para documentar el aspecto
real de ReconcileLab en sus dos plataformas objetivo.

### Ventana principal

`reconcilelab-java-win11-main-window.png`

Muestra la edición moderna con toolbar iconográfica, canvas de estados, HUD de
zoom flotante, inspector lateral y línea de tiempo inferior.

### Ayuda integrada

`reconcilelab-java-win11-help-window.png`

Muestra la ayuda local de la Java Edition y el contexto de conciliación por
monto.

## Criterio editorial

Las capturas sirven como evidencia visual de dos implementaciones del mismo
producto. No se pretende que sean idénticas píxel por píxel: comparten dominio,
flujo y gramática espacial, mientras cada edición conserva el lenguaje visual
de su plataforma.
