# ADR-0001 — Un producto, dos implementaciones

**Estado:** Aceptado  
**Fecha:** 2026-09-03

La edición Java 21/Windows 11 y la edición C++/Windows XP comparten dominio, `.case`, significado de
métricas, estrategias y gramática espacial. Pueden diferir en toolkit, runtime, estilo y packaging.
La edición C++ sirve además como especificación ejecutable para pruebas de paridad.
