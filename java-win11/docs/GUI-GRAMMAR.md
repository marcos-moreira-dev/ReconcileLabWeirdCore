# Gramática GUI — Windows 11

Se conserva la gramática espacial de XP:

```text
MenuBar
ToolBar
Control strip
casos/caso | workspace + zoom | inspector
timeline
status bar
```

La modernización permitida mejora tipografía, contraste, scrollbars, espaciado, foco/hover y respuesta
al resize. No convierte ReconcileLab en un dashboard web.

## Paleta v0.4

- cabeceras de acordeón: azul grisáceo oscuro;
- texto de cabecera: blanco;
- tablas: header azul oscuro y zebra azul pálido;
- canvas: gris carbón;
- procesado: azul;
- compatible: verde;
- descartado: rojo apagado;
- scrollbar: gris azulado con thumb claramente visible.

Objetivo: **sobrio + legible + escritorio tradicional**.
